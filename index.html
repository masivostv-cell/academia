Faltan Permisos en Firebase

Tu base de datos está bloqueando el acceso. Para que la aplicación pueda leer y guardar datos, debes actualizar las reglas de seguridad de Firestore:

  1. Ve a tu consola de Firebase y entra a Firestore Database.
  2. Haz clic en la pestaña Reglas (Rules).
  3. Reemplaza todo el texto por este código: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  4. Haz clic en el botón Publicar.

Nota: Esta configuración es ideal para desarrollar y probar la aplicación rápidamente.
